# Track Map Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Import exact MoTeC `.mt2` maps or generate one stable venue map from telemetry, then connect it to the shared cursor and analytical colouring.

**Architecture:** `core/track` owns parsing and geometry, a dedicated worker map store owns imported/generated entities, and app services expose transferred copies to one canvas widget. All chart/map alignment uses normalized arc fraction; OPFS persistence is deferred to the following plan. Map IDs and operation semantics remain stable, while the persistence plan may extend the worker protocol with restoration and cache-hydration messages.

**Tech Stack:** TypeScript, DataView, Web Worker transferables, Canvas 2D, React, Vitest
